# Jennifer Creates — Software Engineering Portfolio

My personal software engineering portfolio showcasing frontend and backend projects built with React, TypeScript, JavaScript, Node.js, Express, and modern web development tools.

**Live Portfolio:** https://jennifercreates.dev

## About the Portfolio

Jennifer Creates is my personal developer portfolio, designed and built to showcase my transition into software engineering and the projects I've created throughout that process.

The portfolio highlights both frontend applications and backend APIs, with an emphasis on clean interfaces, responsive design, reusable components, and practical software development.

Rather than using a portfolio template, I built the site as a React application and developed a custom visual identity around the **Jennifer Creates** brand.

## Features

- Responsive portfolio layout
- Frontend and backend project organization
- Featured project section
- Individual project cards with technology stacks
- Links to live applications and GitHub repositories
- Downloadable resume
- About and technical skills sections
- Responsive navigation

## Featured Work

### Summarist

A responsive subscription-based book-summary application built with Next.js, TypeScript, Firebase, Stripe, and Tailwind CSS.

Features include authentication, protected content, book discovery, search, audio playback, and subscription functionality.

**Live Demo:** https://becky-virtual-internship-next.vercel.app  
**GitHub:** https://github.com/jennifercreates01/Summarist

### Backend APIs

The portfolio also includes several REST API projects demonstrating backend development with Node.js and Express, including:

- PetPat API
- My Restaurant API
- My Shop API

These projects demonstrate RESTful routing, CRUD operations, validation, filtering, pagination, cart and order functionality, and error handling.

## Design & Development

The portfolio was built with a focus on creating a professional developer identity while keeping the interface clean and easy to navigate.

The application uses reusable React components and structured project data so that projects can be added and maintained without rebuilding the surrounding interface.

Projects are separated into frontend and backend categories to make the range of my development experience easy to explore.
